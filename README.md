## Selected machine learning & research projects

### [Profit-Targeted Churn Retention](https://github.com/rayklanderman/profit-targeted-churn-retention)

**Python · LightGBM · XGBoost · scikit-learn · Decision analytics**  
*Repository: `@rayklanderman`*

Built a churn-modeling and profit-aware retention workflow for a **100,000-customer telecom case dataset**. Expanded **98 source fields to 113 features**, compared multiple classifiers, and evaluated on a **20,000-customer holdout set**.

- **Predictive evaluation:** LightGBM ROC-AUC **0.698**, against a **0.678** baseline.
- **Decision modeling:** Probability calibration, churn-rate reweighting, individual customer value, and intervention costs.
- **Illustrative business outcome:** **$49,526 estimated monthly net profit per 100,000 customers**, **74% projected campaign ROI**, with **16,639 customers selected**.
- **Responsible interpretation:** These are **scenario-based estimates, not realized profits**; the project proposes a randomized pilot to validate actual impact.

[Explore the code and methodology](https://github.com/rayklanderman/profit-targeted-churn-retention) · [Read my technical article](https://www.linkedin.com/pulse/from-churn-prediction-profit-building-machine-100000-klanderman-irche/)

### [Movie Recommendation Project](https://github.com/rayklanderman/mrp-2026)

**Python · Collaborative filtering · SVD · LightGBM**  
*Repository: `@rayklanderman`*

Developed a hybrid recommendation pipeline using **50-factor SVD** and **LightGBM**, trained on approximately **10 million ratings**. Improved the reported competition **public-leaderboard RMSE from 1.21 to 0.82** across iterative submissions. This is a competition result, not a production metric.

[Source code](https://github.com/rayklanderman/mrp-2026) · [Project case study](https://rayklanderman.is-a.dev/projects/movie-recommendation)

**Probability · Statistical inference · Transformers · LLM interpretability**
